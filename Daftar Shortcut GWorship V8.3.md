# ⌨️ Daftar Shortcut Aplikasi GWorship V8.3

Berikut adalah daftar lengkap tombol pintas (*shortcut*) keyboard dan gestur layar sentuh untuk mempermudah pengoperasian aplikasi GWorship.

*(Catatan: Shortcut keyboard ini tidak akan berfungsi jika kursor Anda sedang aktif mengetik di dalam kolom pencarian atau input teks).*

---

### 1. Navigasi Dasar (Pindah Slide & Item)
Gunakan tombol ini untuk berpindah lirik lagu atau ayat alkitab.

| Tombol / Shortcut | Fungsi |
| :--- | :--- |
| **Panah Kanan** (➡️) | Pindah ke bagian lirik/ayat **berikutnya** (Next Slide). |
| **Panah Kiri** (⬅️) | Pindah ke bagian lirik/ayat **sebelumnya** (Prev Slide). |
| **Panah Bawah** (⬇️) | Pindah ke **Lagu atau Ayat berikutnya** yang ada di dalam Setlist. |
| **Panah Atas** (⬆️) | Pindah ke **Lagu atau Ayat sebelumnya** yang ada di dalam Setlist. |
| **Angka 1 - 9** | Langsung memuat Lagu/Ayat dari Setlist sesuai urutan nomornya (1 untuk urutan pertama, dst). |

---

### 2. Navigasi Cepat Lirik Lagu (Lompat Bagian)
Jika lagu sudah diformat dengan tag (seperti [V1], [C1]), Anda bisa langsung melompat ke bagian tersebut menggunakan tombol huruf berikut:

| Tombol | Fungsi / Lompat Ke Bagian |
| :---: | :--- |
| **Q** | Verse 1 (Bait 1) |
| **W** | Verse 2 (Bait 2) |
| **E** | Verse 3 (Bait 3) |
| **R** | Verse 4 (Bait 4) |
| **A** | Chorus 1 / Reff 1 |
| **S** | Chorus 2 / Reff 2 |
| **D** | Chorus 3 / Reff 3 |
| **Z** | Bridge (B1) |
| **X** | Ending (E) |

---

### 3. Kontrol Tampilan Layar Utama
Tombol untuk mengatur apa yang tampil di layar proyektor/eksternal.

| Tombol | Fungsi |
| :---: | :--- |
| **C** | **Clear Text:** Menyembunyikan / memunculkan kembali teks lirik di layar. |
| **B** | **Black Screen:** Menggelapkan layar secara total / mengembalikan layar seperti semula. |
| **L** | **Tampilan Eksternal:** Membuka tab jendela *Display* baru (untuk digeser ke proyektor). |
| **M** | **Perbesar Huruf:** Menambah ukuran *font* teks di layar (+0.5). |
| **N** | **Perkecil Huruf:** Mengurangi ukuran *font* teks di layar (-0.5). |

---

### 4. Overlays (Tampilan Gambar Tambahan)
Tombol untuk menampilkan layar HTML/Gambar tumpukan (*overlay*).

| Tombol | Fungsi |
| :---: | :--- |
| **P** | Menampilkan / menyembunyikan overlay **Logo**. |
| **I** | Menampilkan / menyembunyikan overlay **Intro** (Welcome). |
| **O** | Menampilkan / menyembunyikan overlay **Outro** (Goodbye). |

---

### 5. Gestur Layar Sentuh (Touchscreen)
Jika aplikasi dioperasikan melalui tablet atau layar sentuh, Anda dapat menggunakan usapan jari (*swipe*):

| Gestur Jari | Fungsi |
| :--- | :--- |
| **Ketuk (Tap) Kanan** | Slide berikutnya. |
| **Ketuk (Tap) Kiri** | Slide sebelumnya. |
| **Usap (Swipe) Kanan** | Mengaktifkan/mematikan layar gelap (**Black Screen**). |
| **Usap (Swipe) Kiri** | Menyembunyikan/memunculkan teks (**Clear Text**). |
| **Usap (Swipe) Atas** | Langsung lompat ke **Verse 1** (Bait 1). |
| **Usap (Swipe) Bawah** | Langsung lompat ke **Chorus 1** (Reff 1). |
| **Cubit Buka/Tutup (Pinch)** | Memperbesar atau memperkecil ukuran *font* teks secara manual. |

---

### 6. Lain-lain (Alkitab)
*   **Tombol Enter:** Saat kursor berada di kolom "Ketik Cepat Ayat" pada mode Alkitab, menekan Enter akan otomatis mencari ayat dan menambahkannya ke Setlist.
